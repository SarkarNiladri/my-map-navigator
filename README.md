# My Map Navigator

Free browser-based map navigator using:
- MapLibre GL JS
- OpenFreeMap
- OpenStreetMap / Overpass
- OSRM

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`.
3. Open Settings -> Pages.
4. Under Build and deployment, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Save.
6. GitHub will provide an HTTPS website URL.

Open that HTTPS URL on your mobile and allow location access.
